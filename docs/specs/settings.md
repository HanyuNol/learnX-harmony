# 功能规格：设置页

> 状态：已实现（自动化验收已过；设备项待用户统一验收）　·　关联 PRD：FR-16（与 FR-10 / FR-13 / FR-18 / FR-27 / FR-28 的边界见 §2）　·　分支：main
> 交互参照上游 `robertying/learnX` 的 `screens/Settings.tsx` 与 `data/reducers/settings.ts`
> （设置项清单与默认值）。**只取语义，不移植代码**（ADR-0001）。

## 1. 背景与目标

设置页此前只有"主题"（FR-13）与"学期切换/登出"入口。FR-16 把它收成一个**像样的设置页**：
下载相关的显示项、关于与帮助。这一页是用户唯一能"改配置"的地方，也是**许可归属**必须出现的地方
（ADR-0002：沿用上游 MIT 许可、保留来源归属）——关于页就是那条归属的落点。

## 2. 需求（要什么）

PRD 那行写的是"提醒偏移、文件目录、显示项、关于与帮助"。逐条落位如下：

| PRD 提到的 | 本批处置 |
|---|---|
| 提醒偏移 | **不做**：它是 FR-18（作业截止前本地通知提醒，**P2**）的参数，没有提醒功能时这个偏移值不产生任何效果。`scope-discipline` §2/§3 明确"提前出现的占位算镀金、不为未来预留空壳"，故**连这一行都不出现在界面上**。FR-18 落地时再加 |
| 文件目录 | **已在 FR-10 交付**（缓存目录 / 应用文件目录二选一） |
| 显示项 | 本批做**下载文件名是否省略课程名前缀**（对齐上游 `fileOmitCourseName`）。这是设置项里唯一真正影响"看得见的东西"的显示项 |
| 下载位置 | **三选一放在「下载目录」这一节**：应用内缓存 / 应用内文件目录 / **自定义目录**（系统目录选择器 + 持久化授权，下载平铺落进去）。**位置纠正**：起初我把自定义目录放在「个人信息」页，用户反馈"应该在下载目录那里"后已挪过来——「个人信息」页只留账号 |
| 关于与帮助 | 本批做：**关于**（应用名、版本号、包名、**上游归属与许可**）与**帮助**（使用前提与常见问题） |

**范围内**：

1. 设置页分组呈现：主题、下载目录、显示项、学期切换、关于与帮助、登出；
2. **显示项**：文件名省略课程名前缀（开关），持久化，影响后续下载的文件名；
3. **关于**：应用名、版本号（来自打包信息，不硬编码）、包名、上游项目归属与 MIT 许可说明；
4. **帮助**：使用前提（校园网/校方 VPN）与常见问题（登录、下载位置、找不到文件）。

**不做（属其他 FR）**：

- 提醒偏移与日历/提醒相关（FR-18/FR-19，P2）；
- 课程信息共享（FR-27，P3）；
- 更新检查与更新日志（FR-28，P3）；
- 打开外部链接的"反馈"入口：本项目不做外链跳转（无运营主体、也无对应需求），
  帮助内容全部内置。

## 3. 设计（怎么做）

### 3.1 上游事实（对照基线）

| 事实 | 出处 |
|---|---|
| 设置项集中在 `SettingsState`，含 `fileUseDocumentDir`、`fileOmitCourseName`、`openFileAfterDownload`、日历/提醒若干、`tabFilterSelections` 等 | `data/reducers/settings.ts:13-38` |
| 默认值：`fileUseDocumentDir: false`、`fileOmitCourseName: false` | 同上 |
| 设置页条目：学期切换、日历与提醒、文件设置、课程信息共享、更新日志、帮助与反馈、关于、登出 | `screens/Settings.tsx:99-165` |
| `fileOmitCourseName` 影响下载文件名（不省则拼课程名前缀） | `helpers/fs.ts:55-62` |

### 3.2 模块与文件

| 模块 | 文件 | 职责 |
|---|---|---|
| `storage` | `preferenceStore.ets`（改） | 新增"文件名省略课程名前缀"的读写 |
| `viewmodel` | `settingsStore.ets`（改） | 该项的读写缝 |
| `model` | `file.ets`（改） | `downloadFileName` 增加"是否省略课程名"参数；导出"两种命名"的候选名（兼容旧文件） |
| `repository` | `fileRepository.ets`（改） | 落盘按偏好命名；"已下载"判定**两种命名都看** |
| `native` | `appInfoAdapter.ets`（新） | 应用名/版本号/包名（来自打包信息，不硬编码） |
| `pages` | `Settings.ets`（改） | 分组、显示项开关、"关于与帮助"入口 |
| `pages` | `About.ets`（新） | 关于与帮助的内容页 |

### 3.3 关键规则

1. **版本号不硬编码**：从打包信息读（`app.json5` 的 `versionName`）。硬编码的版本号在发版时
   必然与真值不符，而"关于"页正是用户核对版本的地方。
2. **许可归属必须在界面上**：ADR-0002 要求保留来源归属，故"关于"页写明上游项目与 MIT 许可，
   这是合规项，不是装饰。
3. **改名要兼容旧文件**：切换"省略课程名前缀"后，之前下载的文件仍在原处。故"已下载"判定
   要**两种命名 × 两个目录**都看，否则用户切换后会发现文件"不见了"（与 FR-10 规则 5 同一类问题）。
4. **开关失败要如实**：偏好写入失败时把开关退回真实值并提示，不留"界面与存储不一致"。
5. **不做空壳**：不出现"提醒偏移"这类当前无效果的设置行。
