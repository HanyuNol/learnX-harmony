# 功能规格：全局搜索（课程 · 文件 · 通知 · 作业）

> 状态：已实现（自动化已过；设备已验证，见 §5 末尾）　·　关联 PRD：FR-17（原 P2，按用户要求提前落地）　·　分支：main
> 交互参照上游 `robertying/learnX` 的 `screens/Search.tsx` 与 `components/List.tsx`
> （它把搜索做成一个独立 tab/入口，结果按类型分组）；**只取语义，不移植代码**（ADR-0001）。

## 1. 背景与目标

四个内容维度各自有列表，但**没有一个地方能"按关键词找东西"**：想知道"哪门课提到过 XX"、
"哪个文件叫这个名字"，只能一页页翻。FR-17 提供一个跨四类（课程/文件/通知/作业）的模糊搜索，
结果按四类**自上而下分组预览**，点结果直接进对应详情。

在**课程详情页内**打开的搜索是**限定在这门课**的（范围在预览页顶部写明），两者要能一眼区分。

## 2. 需求（要什么）

1. **入口在每个主页面**：五个标签页（通知/作业/文件/课程/设置）都能打开搜索；
2. **结果预览页**：输入关键词后，按 **课程 → 文件 → 通知 → 作业** 四段自上而下显示，
   每段有标题与命中条数；点一条进对应详情；
3. **课程内搜索**：从课程详情页打开时，只搜这门课，并在顶部标明"在《课程名》内搜索"；
4. **模糊搜索**：大小写不敏感的子串匹配；搜的字段见 §3.3；
5. 无结果时有明确空态；关键词为空时不显示结果（给一句提示引导输入）。

**不做**：

- 索引 / 持久化搜索历史（PRD 无此需求）；
- 服务端搜索接口（学堂没有；本项目是**在已加载的数据里搜**）；
- 高亮关键词（打磨，属后续）。

## 3. 设计（怎么做）

### 3.1 上游事实

| 事实 | 出处 |
|---|---|
| 搜索是独立入口，结果按内容类型分组展示，点结果进各自详情 | `screens/Search.tsx`、`components/List.tsx` |
| 搜索范围是**当前已加载的数据**（本地过滤，不调服务端） | 同上（`data` 来自各维度 store） |
| 课程详情内的搜索限定该课程 | `CourseDetail.tsx` 内的 Search 入口传 courseId |

### 3.2 模块与文件

| 模块 | 文件 | 职责 |
|---|---|---|
| `model` | `search.ets`（新） | 纯逻辑：关键词归一化、逐类匹配、结果分组（可穷举测试） |
| `pages` | `Search.ets`（新） | 搜索页：输入框、范围标题、四段结果、点结果回调 |
| `pages` | `Main.ets`（改） | 五个标签页各挂一个搜索入口；**五个栈共用一个目的地分派**（搜索能打开任意类型的详情） |
| `pages` | `CourseDetail.ets`（改） | 课程内的搜索入口（带 courseId） |

### 3.3 关键规则

1. **在已加载数据里搜，但要先把数据备齐**：搜索页进入时对四个 store 各调一次
   `ensureLoadedFor(当前学期, 当前学期课程)`——否则"没进过文件标签就搜不到文件"，
   用户看到的是"搜索不好用"。这与启动时预加载学期/课程是同一类问题（把内部依赖暴露成了用户操作）。
2. **匹配字段**（大小写不敏感的子串）：
   - 课程：课程名（中/英）与教师名；
   - 文件：标题、描述、分类名；
   - 通知：标题、正文（纯文本）、发布者、课程名；
   - 作业：标题、正文（纯文本）、课程名、教师名。
3. **课程内搜索**：`courseId` 非空时先按课程收窄再匹配；预览页顶栏写"在《课程名》内搜索"，
   与全局搜索**外观上可区分**（标题文案 + 一行范围说明）。
4. **每段最多展示若干条**（本批 10 条）+ "共 N 条"——预览页不承担完整列表的职责，
   避免一次渲染几百条；超出部分提示去对应标签页查看。
5. **关键词为空不发散**：不显示四段结果，给一句"输入关键词开始搜索"。
6. **纯逻辑与平台调用分离**：匹配与分组全在 `model/search.ets`，页面只负责渲染与跳转。

## 5. 验收标准

**自动化可验证（单元测试，不依赖设备）**：

1. 匹配：大小写不敏感；命中标题/描述/课程名/教师名/发布者中任一即算命中；
   关键词为空时四段皆空（不当成"全命中"）；关键词只有空白时同为空；
2. 分组：结果按 课程/文件/通知/作业 固定顺序产出；各段独立计数；无结果时 `isEmpty` 为真；
3. 课程内限定：传 courseId 时其他课程的同名条目不得出现；
4. 静态门：`check arkts`（主 + 测试显式传路径）、`check lint` 零错误；`build` 成功；`check-l10n` 一致。

5. 五个标签页都能打开搜索页；
6. 输入关键词后四段结果自上而下出现，点某条能进对应详情；

## 6. 风险 / 待定

| 项 | 说明 | 处置 |
|---|---|---|
| 只搜已加载数据 | 学堂无搜索接口，本项目只能在本地已取到的数据里搜 | 进入搜索页时主动 `ensureLoadedFor` 四类（规则 1）；数据量大时仍是内存过滤，够用 |
| 每段 10 条的截断 | 预览页不是完整列表 | 显示"共 N 条"并提示去对应标签页看全部 |
| 中文分词 | 只做子串匹配，不做分词/拼音 | 与需求（模糊匹配）一致；拼音/分词属打磨 |
