# ADR-0002：沿用上游 MIT 许可并保留来源归属

## 状态
已接受

## 背景

本项目是上游 [robertying/learnX](https://github.com/robertying/learnX) 的功能重建。上游仓库 `LICENSE` 为 **MIT License，Copyright (c) 2026 Rui Ying**。

本项目不复制上游任何代码，但参照其功能清单、数据模型语义与接口对接方式。需要明确：本项目采用什么许可、如何标注来源。

## 决策

本项目采用 **MIT 许可**，并在 README 与 LICENSE 中**明确保留对上游 learnX 及其依赖 `thu-learn-lib` 的来源归属**。

## 理由

- 与上游许可一致，避免衍生作品在许可上产生歧义；MIT 对本项目后续可能的开源分发也最宽松。
- 虽然本项目为独立实现（不构成 MIT 意义上的代码衍生），但功能设计与接口对接方式源自上游，**主动标注来源是应有的学术与工程礼节**，也便于使用者理解两个项目的关系。
- 上游作者及 `thu-learn-lib` 作者对网络学堂逆向对接的贡献是本项目得以成立的前提。

## 后果

- **正面**：许可清晰；来源可追溯；避免"重写后在许可上切割来源"的道义风险。
- **负面**：需在 LICENSE 与 README 维护归属声明，属长期低成本的文档义务。
- **后续约束**：LICENSE 中的年份与持有者不得留空；README 必须给出上游项目链接与"非官方客户端"声明。

## 备选方案

- **Apache-2.0**：与上游不一致，且引入专利条款等额外复杂度，对客户端项目无实际收益。
- **保留所有权利（闭源）**：本项目大量参照上游 MIT 作品的功能设计，闭源既不必要也不合适；且无商业约束需求。
